# SES AI Matcher (案件・人材AI自動マッチング＆提案メール生成システム)

SES（システムエンジニアリングサービス）およびIT人材紹介事業における**営業マッチング業務を全自動化・高度化するフルスタックWebアプリケーション**です。

---

## 🌟 実装された機能

### 【機能１】人材起点マッチング ＆ 提案メール自動生成
- **スプレッドシート ＆ 職務経歴書連携**:
  - GoogleスプレッドシートやCSVから人材データを取り込み。
  - 添付された業務経歴書（PDF / Word / テキスト）からスキルや職務履歴を自動抽出。
- **適合度判定 ＆ 理由提示**:
  - 受信した案件メール群から、対象の技術者に提案可能な案件を自動探索。
  - **適合度スコア（0〜100%）** と **適合理由（強み・一致要件）**、**懸念点（要確認項目）** を明示。
- **提案メール自動作成（60%以上トリガー）**:
  - **適合度60%以上の案件**に対して、パートナー企業宛ての魅力的な推薦提案メールを自動下書き生成。
  - 営業担当者が画面上で文面を確認・編集し、ワンクリックでコピーまたはメーラー起動が可能（営業担当者が送信判断）。

### 【機能２】双方向のTop 10探索（スプレッドシート ⇔ 受信メール）
- **機能２-A（案件 ➜ 人材メール探索）**:
  - スプレッドシート上の「案件」を選択すると、受信した「人材メール」群から最適な技術者候補**10名**を適合度順にピックアップ。
- **機能２-B（人材 ➜ 案件メール探索）**:
  - スプレッドシート上の「人材」を選択すると、受信した「案件メール」群から最適な候補案件**10件**を適合度順に探索。

### 【機能３】メール同士の全自動クロス突合（案件メール × 人材メール）
- メーリングリストに届くパートナー同士の「案件メール」と「人材メール」をAIが自動分類・構造化。
- 案件と人材を網羅的に総当たり突合し、商談成立確度の高いペアをスコア順に自動レコメンド。

## 🚀 アプリケーションの起動方法

### 1. ワンクリック起動
ターミナルで本ディレクトリ（`ses-ai-matcher`）に移動し、以下を実行します：

```bash
./run.sh
```

ブラウザで以下のURLを開きます：
👉 **http://localhost:8000**

## 💡 便利な機能・Tips
- **デモデータ即座確認**: 画面右上の「リセット」ボタンを押すと、いつでも日本のSES市場に沿ったリアルな案件・人材・メールサンプルを復元できます。
- **スプレッドシート連携**: 画面右上の「シート連携 / 取込」から、Googleスプレッドシートの公開共有リンクを貼るだけで一括取り込みが可能です。
- **経歴書アップロード**: 人材カードの「経歴書」ボタンからPDFやWordファイルをドラッグ＆ドロップすると、AIがテキストと新スキルを自動抽出します。
- **Gemini API連携**: 環境変数 `GEMINI_API_KEY` を設定することで、Google Geminiモデルによるさらに高度な自然言語推論が有効化されます（未設定時でも高品質な内蔵エンジンで完全動作します）。
